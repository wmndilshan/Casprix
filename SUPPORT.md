# Support

Casprix is an actively developed, pre-stable language toolchain.

- Use GitHub Issues for reproducible bugs.
- Use GitHub Discussions for usage questions and design proposals.
- Read [README.md](README.md), [docs/FEATURES.md](docs/FEATURES.md), and
  [docs/CASPRIX_SYNTAX_EBNF.md](docs/CASPRIX_SYNTAX_EBNF.md) before reporting a
  syntax problem.
- Include the output of `casprix --version`, the operating system, compiler
  toolchain, complete command, and a minimal `.cpx` reproducer.

There is currently no commercial support or stability guarantee. Public APIs,
the standard library, package format, and generated ABI may change before a
stable release.
