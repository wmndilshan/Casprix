Runtime and MIR bugs fixed:
ARC payload alignment is now explicit and validated, including 32-byte and 64-byte payload alignment.
ARC allocation size arithmetic now checks for overflow before allocation.
Weak upgrade now uses a checked CAS loop and fails once destruction begins.
ARC finalization now preserves weak-header lifetime correctly and zeroes payloads when explicit weak refs remain.
Destructor reentrancy and peer releases during cycle teardown no longer crash with over-release aborts.
mem_arc_release no longer dereferences a possibly freed header after release.
Cycle GC now restores externally reachable gray subgraphs before sweep and only one subsystem performs final physical destruction.
Cycle GC byte/object accounting is updated on successful collection.
MirFunction parameter SSA values now initialize after the value-type table exists.
MIR validation now checks CFG symmetry, block-id uniqueness, phi/predecessor consistency, duplicate SSA definitions, same-block use-before-def, and non-dominating uses.
MIR validation is run after mem2reg, after inlining/optimization, and before backend emission.
